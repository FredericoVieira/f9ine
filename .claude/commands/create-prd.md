# Create PRD

Ask clarifying questions first — scope, user, edge cases, "done" — before drafting. Don't guess.

```markdown
# PRD: [name]

## Problem

## Goals / Non-goals

## User stories

## Requirements

[numbered, testable]

## Edge cases & error states

## Success criteria

## Open questions
```

Save to `.agents/PRDs/[slug].md`. Flag open questions explicitly — don't bury them.
